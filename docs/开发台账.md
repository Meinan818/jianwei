**关键结论（供后续开工参考）**

- 直接 `npx vite build` 得到的是平台托管产物：HTML 里含 `{{appName}}/{{appAvatar}}/{{tenantId}}` 占位符、
  三个字节跳动外链脚本、右下角妙搭水印（`z-index: 2147483647`）。对外部署必须走 `npm run build:standalone`。
- 平台 SDK `@lark-apaas/client-toolkit-lite` 无需写兼容层：`scopedStorage` 本质是给 localStorage 加
  `__miaoda_<appId>__:` 前缀，取不到 appId 时退化为 `__miaoda___global__:` 前缀，功能正常。
  注意副作用：换运行环境后旧的本地数据不会自动迁移。
- 构建产物目录是 `dist/client`（不是 `dist/`），Cloudflare Pages 的「输出目录」要按此填写。
- 9 态订单枚举、未读三字段（`unreadCustomer/unreadMerchant/unreadRider`）与 SQL 侧一致，第 2 期地基可用。
